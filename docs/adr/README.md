# 设计决策记录（ADR）

每篇记录一个难以撤回的决定：当时的背景、决定了什么、带来的后果、没有选的方案。

| 编号 | 决定 | 一句话 |
| --- | --- | --- |
| [0001](0001-the-model-never-owns-the-rules.md) | 模型不拥有规则 | 规则只在确定性引擎里；模型只提出动作或给事实配一句话 |
| [0002](0002-an-event-log-for-replay-and-concurrency.md) | 用事件日志保存对局 | 只存事件，状态靠重放；同一份数据支撑重启恢复、并发控制和回放 |
| [0003](0003-least-privilege-agents-with-a-fallback.md) | AI 玩家最小权限，失败就回退 | 只看自己的视图、只能提自己的合法动作；两次不行由机器人代打 |
